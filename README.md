A beautiful, modern, and responsive single-page web application featuring a functional calculator and an inspiring quotes section. 

## 🚀 Features
- **Interactive Calculator:** Perform basic arithmetic calculations easily.
- **Dynamic Quotes:** Display engaging and inspiring mathematical quotes.
- **Modern UI:** Clean design with a beautiful background and responsive navigation bar.
- **SPA Behavior:** Smooth section switching without reloading the page.

## 🛠️ Tech Stack
- **HTML5:** For structured layout and semantic elements.
- **CSS3:** For modern styling, flexbox positioning, and clean visual effects.
- **JavaScript (ES6):** For dynamic page switching and calculator logic.
